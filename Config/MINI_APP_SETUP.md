# Запуск Telegram Mini App в TRAVA (Windows)

Mini App работает через локальную программу TRAVA. Отдельный VPS не нужен.

## Как это устроено

1. При запуске TRAVA открывает локальный API на `127.0.0.1:8765`.
2. TRAVA запускает Cloudflare Quick Tunnel и получает временный HTTPS-адрес.
3. Программа автоматически передаёт этот адрес Telegram-боту и обновляет кнопку меню «Открыть TRAVA».
4. Флорист и курьер открывают Mini App из Telegram с любого подключения к интернету.
5. Заказы создаются и сохраняются в локальной SQLite-базе TRAVA.

Компьютер магазина и интернет должны быть доступны всё время, когда сотрудники используют Mini App. После закрытия TRAVA туннель отключается. При следующем запуске создаётся новый адрес; бот автоматически обновляет кнопку меню.

## Первоначальная настройка

### 1. Установить Cloudflare Tunnel

Откройте PowerShell и выполните:

```powershell
winget install --id Cloudflare.cloudflared -e
```

После установки полностью перезапустите VS Code и проверьте:

```powershell
cloudflared --version
```

Если команда не найдена, перезапустите Windows или добавьте папку с `cloudflared.exe` в системный PATH.

### 2. Настроить переменные

Создайте файл `Config/.env` на основе `Config/.env.example`.

Укажите:
- `TELEGRAM_BOT_TOKEN` — токен вашего бота.
- `FLORIST_TELEGRAM_IDS` — Telegram ID флористов через запятую.
- `MINI_APP_PORT=8765`.

Оставьте `MINI_APP_URL=` пустым. Тогда временный HTTPS-адрес будет создаваться автоматически при каждом запуске TRAVA.

Файл `Config/.env` содержит секреты и не должен попадать в Git.

### 3. Запустить TRAVA

Запустите приложение обычным способом. Если Cloudflare Tunnel установлен и доступен в PATH:
- локальный API запустится автоматически;
- бот подключится к Telegram;
- после создания туннеля Telegram-бот получит новый HTTPS-адрес;
- кнопка меню Mini App обновится автоматически.

Флористу нужно отправить боту `/start`. Курьер сначала подключает аккаунт одноразовым кодом из настольной TRAVA, затем также отправляет `/start`.

## Ограничения бесплатного Quick Tunnel

- Адрес `trycloudflare.com` временный и меняется после перезапуска туннеля.
- Не закрывайте TRAVA, пока сотрудники пользуются Mini App.
- Если компьютер выключен, интернет пропал или туннель остановился, Mini App временно недоступен.
- SQLite-база остаётся на компьютере магазина; наружу публикуется только HTTP-доступ к Mini App через HTTPS-туннель.

Для постоянного адреса можно позже настроить именованный Cloudflare Tunnel и указать его HTTPS-адрес в `MINI_APP_URL`.
