# Настройка Telegram Mini App TRAVA

## Что уже реализовано

- Флорист открывает Mini App из Telegram и создаёт заказ.
- Курьер видит только назначенные ему актуальные заказы.
- Курьер может начать доставку и отметить заказ доставленным.
- Все данные сохраняются в ту же SQLite-базу, которую использует настольная TRAVA.
- API принимает запросы только с корректной подписью Telegram Mini App.
- Создание заказов доступно только Telegram ID из списка флористов.

## 1. Настройте Config/.env

Добавьте параметры:

```env
TELEGRAM_BOT_TOKEN=токен_бота
MINI_APP_PORT=8765
MINI_APP_URL=
FLORIST_TELEGRAM_IDS=123456789
```

В `FLORIST_TELEGRAM_IDS` укажите Telegram ID флориста. Если флористов несколько, перечислите ID через запятую. Узнать ID можно через бота @userinfobot.

## 2. Опубликуйте локальный сервер по HTTPS

Telegram требует HTTPS-адрес для Mini App. Приложение TRAVA запускает локальный сервер на порту 8765. Для проверки можно использовать Cloudflare Quick Tunnel:

1. Установите cloudflared на компьютер, где запускается TRAVA.
2. Запустите настольное приложение TRAVA.
3. В отдельном терминале выполните:

```bash
cloudflared tunnel --url http://localhost:8765
```

4. Cloudflare покажет публичный адрес вида `https://random-name.trycloudflare.com`.
5. Запишите этот адрес в `MINI_APP_URL` в `Config/.env`:

```env
MINI_APP_URL=https://random-name.trycloudflare.com
```

6. Перезапустите TRAVA и отправьте боту команду `/start`.

Quick Tunnel выдаёт временный адрес. При новом запуске туннеля адрес может измениться — тогда обновите `MINI_APP_URL` и перезапустите TRAVA. Для постоянной работы настройте именованный Cloudflare Tunnel с постоянным доменом.

## 3. Подключение курьера

Подключение курьера осталось прежним:

1. Добавьте курьера в настольной TRAVA.
2. Нажмите «Подключить» и получите одноразовый код.
3. Курьер отправляет боту `/start`, затем вводит код.
4. После подключения он открывает кнопку «Открыть TRAVA».

Флористу код курьера не нужен: достаточно добавить его Telegram ID в `FLORIST_TELEGRAM_IDS`.

## Важно

- Компьютер с TRAVA должен быть включён, приложение должно работать, а туннель — оставаться запущенным.
- Не публикуйте токен Telegram-бота и файл `Config/.env`.
- Порт Mini App не нужно открывать напрямую в роутере: используйте HTTPS-туннель.
